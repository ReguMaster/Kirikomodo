### Kirikomodo는요

**Kirikomodo**는 오버워치의 키리코를 모티브로 만든 Windows 데스크톱 컴패니언 프로젝트예요.

화면 속 키리코가 자연스럽게 움직이고, 사용자에게 반응하며, 일상 속 작은 동반자가 되는 경험을 만들고 있어요.

### 이런 기능을 만들고 있어요

| 기능                  | 설명                                                     |
| :-------------------- | :------------------------------------------------------- |
| **Live2D 캐릭터**     | 표정과 움직임으로 감정을 표현해요.                       |
| **데스크톱 상호작용** | 클릭이나 드래그 같은 행동에 반응해요.                    |
| **자율 행동**         | 가만히 있을 때도 자연스럽게 행동해요.                    |
| **대화와 기억**       | 사용자와 대화하고 상호작용을 기억하도록 만들 계획이에요. |

### 개발 현황

이제 막 개발을 시작했어요. 기능과 구현 방식은 개발하면서 조금씩 다듬어 갈 예정이에요.
