## 판단

- **상반신 크롭 `[0, 0, 732, 1000]`** 을 1024x1400 캔버스에 1.399 배로 올린다(머리 끝~허리 매듭·늘어진 구슬). 하반신은 별도 `full_body` 계획으로 미룸
- 3D 렌더라 음영이 레이어 경계와 섞여 있어 색 기반 초안 분리는 **참고용(_REF)** 에 그친다. 머리카락/눈/입/부적 경계는 수작업 분리 필요
- 포즈상 가려진 영역(뒷머리, 왼팔 전체, 입 안, 귀 등 17장)은 레퍼런스에 없다 → 복원 제작 목록(`docs/live2d-kiriko-parts.md`)
- 명세 16.1·16.14 대로 이 이미지는 **비주얼 레퍼런스** 다. 최종 PSD 는 이를 보고 새로 그리는 자체 원화여야 하며, 파생물은 배포하지 않는다(`docs/asset-rights.md`)
